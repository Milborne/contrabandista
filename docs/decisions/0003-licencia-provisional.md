# ADR 0003: Apache-2.0 provisional

- Estado: provisional; confirmar antes de beta pública.
- Decisión: publicar inicialmente bajo Apache License 2.0.
- Motivo: licencia permisiva conocida con concesión expresa de patentes, coherente con maximizar adopción en Hito 0. El plan mantiene abierta la decisión frente a MIT/AGPL; revisar con mantenedores antes del lanzamiento.
